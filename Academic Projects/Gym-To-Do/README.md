# 📱 Exercise TODO App

This is a mobile application I developed using **Kotlin** in **Android Studio** as part of an academic project for my certification.

The app focuses on managing exercise routines with basic features like creating, editing, deleting, and activating routines. It was built for **educational purposes only**.
